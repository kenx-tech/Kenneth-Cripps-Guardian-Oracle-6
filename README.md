4. **Energy Bounds Check**: Confirms task energy consumption did not violate sovereign power thresholds.
5. **Output Schema Integrity**: Validates syntax, types, and structural invariants.
6. **Semantic Equivalence Check**: Verifies that alternative routes produce coherent, truthful outputs.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.0.0 or higher
- npm or bun

### 1. Clone & Install
```bash
git clone https://github.com/guardianoracle/guardian-oracle.git
cd guardian-oracle
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and configure your API keys:
```bash
cp .env.example .env
```
Key variables:
```ini
# Gemini API Key (Server-side)
GEMINI_API_KEY=your_gemini_api_key_here

# Firebase Configuration (Client-side)
VITE_FIREBASE_API_KEY=your_firebase_key
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_APP_ID=your_app_id
```

### 3. Run Development Server
```bash
npm run dev
```
The server will start on port `3000` (available at `http://localhost:3000`).

### 4. Build for Production
```bash
npm run build
npm run start
```
